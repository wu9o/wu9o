我有前端架构与开发者基础设施的工程背景，关注如何把分散的信息变成可检索、可复用的知识，以及如何让 AI 进入实际工作流。

### 关注方向

- **知识工程**：探索知识的采集、组织、检索与持续更新。
- **知识发布**：通过 Cogita 连接内容、主题与展示，把工程经验整理成可阅读的博客、文档和知识库。
- **工程效率**：从日常开发中的具体问题出发，实践 AI 辅助工作流，编写小而实用的工具。
